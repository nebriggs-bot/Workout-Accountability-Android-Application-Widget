# Workout-Accountability-Android-Application-Widget

This application analyzes workout history and displays it along with statistics to help inform the user on how active they have been in a given year, or time period. The application provides statistics in multiple formats; 1) There is a widget that shows which days over a specified 365 day period you have recorded a workout activity, 2) There is a widget that shows all logged workout activities on a monthly view, 3) Statistics are provided in the application for a calendar year. 

The application prompts the user to provide permission for Health Connect to receive activity data from Garmin Connect (or an alternative application) and provide this data to this application from Health Connect. The application allows the user to import a csv file output from the Garmin Connect website and then stores the data within the application.

On the Garmin Connect website: Activities > All Activities > Export CSV
